## 1. 데이터와 비교 구조

- **무엇과 무엇을 비교하나요?** 그룹 몇 개, 독립인가 짝인가, 시간 경과인가
- **n은 무엇인가요?** 생물학적 반복(사람 한 명, 동물 한 마리)만 n이에요. 같은 시료의 세포 수천 개는 n이 아니에요.
- **대조군**은 무엇인가요?
- **배치**: 그룹과 실험 날짜 · 배치가 겹치지 않게 섞어요. 보정보다 설계가 먼저예요.
- **공개 데이터부터**: GEO · 공개 아틀라스로 먼저 시험해 볼 수 있나요?

> 통계는 [3장 통계 익히기](#/q/ch3-stats)에서 더 자세히 다뤄요.

## 2. 가정 표

[가설 세우기](#/q/ch2-hypo)에서 적은 가정마다 두 점수를 매겨요.

| 가정 | 위험도 1–5 | 확인까지 (개월) |
|---|---|---|
| 공개 데이터에 원하는 세포가 충분하다 | 2 | 1 |
| 위험 변이가 이 세포의 크로마틴에 농축된다 | 3 | 3 |
| 찾은 유전자가 실험으로 재현된다 | 4 | 12 |

위험도: 1 거의 확실(90% 이상) · 2 그럴 것 · 3 반반 · 4 아마 아님 · 5 거의 안 됨(10% 미만)

**내가 틀렸다는 쪽으로** 정직하게 매겨요.

## 3. 위험 신호와 초록불

| 🚩 위험 신호 | 🟢 초록불 |
|---|---|
| 위험도 4–5인 가정을 1년 반 뒤에야 확인 | 가장 위험한 가정을 6개월 안에 확인 |
| 위험도 4–5인 가정이 2–3개 넘음 (기적이 여러 번 필요) | 결과가 여러 가지여도 의미가 있음 |
| 위험한 가정이 줄줄이 이어짐 | A가 안 되면 B로 갈 길이 있음 |
| 쉬운 것만 먼저 하고 위험한 건 미룸 | 위험이 일정 전체에 나뉘어 있음 |

> 3년 뒤에야 확인되는 위험도 5짜리 가정이 있다면, 다른 주제를 고르는 게 나아요.

## 4. go / no-go

가장 위험한 가정 하나를 **가장 빨리, 거칠게라도** 확인할 방법을 정해요.

| 칸 | 적을 것 |
|---|---|
| 질문 | 정확히 무엇을 확인하나 |
| 방법 | 가장 직접적인 확인 (공개 데이터, 작은 예비 분석) |
| go | 이런 결과면 계속 |
| no-go | 이런 결과면 방향을 바꿈 |
| 기간 | 언제까지 |

위험을 줄이는 방법: 확인을 앞당기기 · 후보를 여러 개 · 질문을 조금 바꾸기 · 다른 데이터 · 보완 방법 더하기

## 5. 분석 방법 고르기

- 툴 논문의 자랑보다 **독립된 벤치마크 논문**을 먼저 봐요.
- 그 방법의 **가정이 내 데이터와 맞나요?** (분포, 배치 구조, 참조 데이터, 해상도)
- **재현성**: 코드 · 데이터 공개, 버전, 최근까지 관리되나
- **리뷰어를 설득할 확인**을 계획해요: 두 방법 비교, 알려진 마커로 확인, 음성 대조, 일부만 뽑아 다시 돌려 보기

> 남의 논문에서 방법을 뜯어보는 연습은 [3장 Methods 해부하기](#/q/ch3-methods)에서 해요.

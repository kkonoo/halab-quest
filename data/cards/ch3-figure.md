# 3장 · 5. Figure 만들기 — 게임 내 가이드 카드

> 출처: Lab Manager 팁 "그림 만들기", "분석: 통계 검정 · plot 매칭표"
> 논문 전체 그림의 순서와 저널 규격은 4장 Figure 스토리보드에서 다뤄요.

---

## 1. 메시지 정하기

**그림 하나 = 메시지 하나.** 그리기 전에 이 그림의 결론을 한 문장으로 먼저 써요.
✗ "그룹별 발현량" → ✓ "KO 세포에서 X 발현이 절반으로 줄었어요"

- 이 문장이 발표 슬라이드 제목, figure legend 첫 문장, 4장 Figure 순서 카드가 돼요.
- 보는 사람이 **3초 안에** 어디를 봐야 할지 알게: 강조는 한 곳만.
- 메시지에 필요 없는 패널은 보충 자료로 보내요.

---

## 2. 그래프 고르기

데이터 종류와 비교 구조에 맞춰 골라요.

| 보여 줄 것 | 그래프 |
|---|---|
| 두세 그룹의 연속값 | dot plot (점 전부 + 평균±SD), box + 점, violin |
| 같은 대상의 전 · 후 | before–after plot (짝을 선으로 연결) |
| 두 연속 변수의 관계 | scatter + 회귀선 |
| 시간에 따른 변화 | 선 그래프 (평균±SD, 개체별 얇은 선) |
| 개수 · 비율 | 막대 (y축 0부터), 100% 누적 막대 |
| 유전자 수천 개 비교 | volcano, MA plot, heatmap (z-score) |
| 시료가 그룹별로 모이나 | PCA (축에 설명 분산 %) |
| 생존 | Kaplan–Meier 곡선 + number at risk |

- 연속값을 **평균 막대만**으로 그리지 않아요. 분포가 가려져요.
- n이 작으면(대략 10 이하) 점을 전부 보여 줘요.
- 더 많은 상황은 Lab Manager "통계 검정 · plot 매칭표"에 있어요.

---

## 3. 데이터 배치

- 비교할 것은 **나란히, 같은 축 범위로** 놓아요.
- 대조군을 맨 앞(왼쪽)에. 그룹 순서는 논문 전체에서 같게.
- 같은 그룹은 논문 전체에서 **같은 색**.
- 범례보다 점·선 옆에 바로 이름을 붙여요.
- 패널이 여럿이면 왼쪽 위부터 A → B → C, 격자에 맞춰 정렬해요.

---

## 4. 축과 통계 표시

- 모든 축에 **이름 + 단위**. 로그 축이면 표시해요.
- 막대 그래프의 y축은 0부터.
- 오차 막대 종류(SD / SEM / 95% CI)와 **n이 무엇인지**를 legend에 적어요.
- 유의 표시: 비교한 쌍을 선으로 잇고, 정확한 p 또는 기호(* p < 0.05 …)를 legend에 정의해요.
- 검정 이름과 다중비교 보정도 legend에 적어요.

---

## 5. HaLab Plots로 다듬기

**알맹이는 코드에서, 보기는 HaLab Plots에서.**

| 코드에서 정하기 (알맹이) | HaLab Plots에서 다듬기 (보기) |
|---|---|
| 어떤 데이터 · 어떤 그래프 | 글씨 크기 |
| 축 · 그룹 순서 · 통계 표시 | 점 크기 |
| 필터 · 정규화 · 계산 | 색 |

- 내용이 바뀌는 수정(데이터, 축, 통계)은 **꼭 코드에서** 해요. 그래야 다시 그려도 같은 그림이 나와요.
- 보기만 바꾸는 수정(글씨 · 점 크기 · 색)은 HaLab Plots에서 해요. 공동연구팀도 같은 그림을 보고 바로 고칠 수 있어요.
- 색: 빨강–초록을 같이 쓰지 않아요 (색맹). 색맹에 안전한 Okabe–Ito 팔레트를 추천해요.
- 논문에 넣을 때의 그림 폭 · 글씨 pt · 해상도는 4장 Figure 스토리보드에서 확인해요.

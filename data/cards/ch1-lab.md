## 1. 우리가 하는 연구

**유전체학과 의학을 연결해요.**
복합 질환의 유전적 · 후성유전적 기전을 밝히고, 이를 바탕으로 새로운 바이오마커와 치료 표적을 찾아요.

| 연구 분야 | 무엇을 |
|---|---|
| 멀티오믹스 통합 | 유전체 · 후성유전체 · 전사체 · 단백체 · 메타유전체를 벌크 · 단일세포 · 공간 해상도로 |
| GWAS 통합 | 복합 형질 관련 변이를 조절 요소와 표적 유전자에 연결 |
| 질병 기전 | 암, 신경발달 · 신경정신 질환, 바이러스 감염, 자가면역질환 |

> 기초 의과학에서 출발해서, 결과를 정밀 의료로 이어 가요.

## 2. 우리가 일하는 방식

| 언제 | 무엇을 |
|---|---|
| 코어타임 10–18시 | 회의 · 같이 하는 작업이 가능한 시간 (출퇴근은 자율) |
| 주 1회 | 랩미팅: Progress report (영어) + Journal club (한국어) |
| 주 1회 | 개인 미팅: 연구 진행 점검 |
| 연 2회 | 랩 OT: 신입은 첫 OT 꼭 참석 |

- 실험 · 분석 노트는 **매주** 업데이트해요.
- 휴가는 일정을 미리 공유하고 자율로 써요 (공동 프로젝트 일정 고려).

## 4. 첫 한 달

**신입생의 첫 1개월**
- 데이터 분석 기본기: Linux, R/Python → 3장 분석 기본기 익히기
- 분야 탐색 · 문헌 검색 · 논문 읽기 → 1장 나머지 퀘스트

**우리 연구실 기준**

| | 못해도 괜찮은 것 | 꼭 해야 하는 것 |
|---|---|---|
| 통계 | 수식 증명 | 개념의 의미 이해 |
| 코딩 | 처음부터 끝까지 혼자 짜기 | 코드를 이해하고 필요한 부분 고치기 |
| 연구 | 모든 개념 외우기 | 데이터 해석, 의미 있는 토론 |

**과정별 목표**
- 석사: 주어진 연구를 이해하고, 기존 분석 방법을 이해해서 쓰기
- 박사: 연구 주제를 스스로 찾고, 주도적으로 연구하기

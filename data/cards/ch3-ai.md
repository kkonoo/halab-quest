# 3장 · 6. AI 활용하기 — 게임 내 가이드 카드

> 출처: Lab Manager 팁 "공부 · AI 활용", RNA-seq analysis 교재 W11 "바이브코딩 팁", advanced BI 교재 W2 "R 스크립트, AI 보조 코딩과 재현성"
> 학교 · 저널의 AI 사용 규정이 항상 먼저예요.

---

## 1. 코드 작성 · 디버깅

**AI가 잘하는 것:** R · Python 코드 초안, 오류 메시지 설명, 코드 한 줄씩 설명

**좋은 질문 틀:** 상황(나는 누구) → 목표 → 자료 → 원하는 형식 → 확인 요청
> "R에서 이 데이터(열 이름과 구조는 아래)를 two-way ANOVA로 분석하고 ggplot2로 dot plot을 그리고 싶어. 코드와 각 줄 설명, 가정 확인 방법도 알려 줘."

- 진짜 데이터 대신 **열 이름 · 구조만**, 또는 가짜 예제 데이터를 붙여요.
- 받은 코드는 **읽고 나서** 실행해요. 모르는 함수는 도움말(`?함수이름`)부터 봐요.
- 오류가 나면 오류 메시지를 그대로 복사해 붙이기 전에, 어느 줄에서 왜 났는지 먼저 읽어 봐요.

---

## 2. 읽기 · 쓰기 보조

**써도 되는 일**
- 개념을 내 수준에 맞게 설명받기
- 공개된 논문의 초록 요약 ("초록에 없는 내용은 모른다고 해" 붙이기)
- 공개해도 되는 내 글(공부 노트 등)의 문법 · 흐름 다듬기 ("내용과 주장은 바꾸지 말고, 바꾼 곳을 표로")

**조심할 것**
- AI는 **참고문헌 · 수치를 지어낼 수 있어요.** PubMed · DOI로 실제 있는지 꼭 확인해요.
- **미발표 원고 · 데이터는 넣지 않아요.** 원고는 4장 논문 원고 쓰기에서 교수님과 같이 고쳐요.

---

## 3. AI 결과 검증

**확인하는 3가지**
1. **원문 확인** — 참고문헌 · 수치는 PubMed · 논문에서 직접
2. **교차 확인** — 교재 · 리뷰 · 선배 · 교수님께 한 번 더
3. **직접 해 보기** — 코드는 작은 예제로 돌려 보고, 계산은 손으로 다시

**"실행됐다"는 "맞다"가 아니에요**
- 답을 아는 작은 예제로 먼저 돌려 봐요.
- 단계마다 샘플 수 · 유전자 수 같은 숫자가 예상과 맞는지 봐요.
- 통계 방법 추천은 통계 실습실과 Lab Manager 매칭표로 확인해요.

**✓ 미션:** AI가 쓴 코드나 답변 하나를 골라 위 3가지로 확인해 보세요.

---

## 4. 연구윤리 · 데이터 보안

**🔴 어떤 AI에도 넣지 않기**
- 환자 개인정보 · 의무기록 · 사람 시료 정보
- 미발표 데이터 · 원고
- 심사 중인 원고 (리뷰어로 받은 남의 원고 포함)
- 과제 제안서 · 특허 전 아이디어
- 계정 · 비밀번호 · 서버 접속 정보

**논문 · 과제에 쓸 때**
- 투고할 저널과 학교의 AI 정책을 확인해요. AI는 저자가 될 수 없어요.
- AI를 쓴 사실은 Methods나 Acknowledgments에 밝혀요.
- AI로 데이터 그림(블롯 · 현미경 사진 등)을 만들거나 고치면 안 돼요.
- 내용 · 주장 · 해석의 책임은 저자에게 있어요.

> 넣어도 되는지 애매하면, 넣기 전에 교수님께 먼저 물어봐요.

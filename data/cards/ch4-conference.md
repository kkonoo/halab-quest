# 4장 · 4. 학회 발표 — 게임 내 가이드 카드

> 출처: Lab manual(학회·워크숍 지원 규칙), 3장 "랩미팅 발표" 카드
> 슬라이드 기본 규칙과 질의응답은 3장 랩미팅 발표에서 다뤘어요. 여기서는 연구실 밖 청중 앞에서 달라지는 점만 다뤄요.

---

## 1. 학회에 가기 전

**우리 연구실 규칙**
- 학회에 가면 **발표가 우선**이에요 (구두나 포스터).
- **초록 제출일 최소 1주 전**에 교수님께 보고해요.

**학회 준비 흐름**
교수님께 보고 → 초록 제출 → 발표 자료 만들기 → 연습 → 학회 → 발표 기록

**초록 쓰기**
- 학회 규정을 먼저 확인해요: 글자 수, 형식, 마감일, 발표 형식 선택(구두·포스터)
- 순서: 배경 1~2문장 → 질문 → 방법 → 주요 결과(수치) → 결론·의미
- 결과는 "유의하게 달랐다"로 끝내지 말고 수치로 써요.
- 제목에 핵심 결과를 담아요.
- 제출하기 **최소 1주 전**에 교수님과 공동저자에게 확인받아요.

---

## 2. 학회 구두 발표

**랩미팅과 다른 점**
- 청중이 우리 연구를 처음 들어요 → 지난번 이야기(In the previous) 없이, "왜 중요한가"부터 시작해요.
- 잘 안 된 결과는 빼요. 메시지에 필요한 결과만 보여줘요.
- 시간을 꼭 지켜요. 질문 시간이 발표 시간에 포함되는지 확인해요.

**구성 (10~15분)**
**질문(왜 중요한가) → 가설 → 핵심 결과 3개 → 결론 한 장 → 감사**

- 핵심 결과는 3개면 충분해요. 결과 하나 = 메시지 하나.
- 결론 슬라이드는 질문받는 동안 화면에 띄워 둬요.
- 감사 슬라이드에는 공동저자, 연구실, 연구비(과제 번호)를 넣어요.

---

## 3. 포스터

**지나가는 사람이 3초 안에 멈추게**
- 제목에 결론을 문장으로 써요.
- 그림 위주로, 글은 짧게. 1.5 m 거리에서 읽혀야 해요.
- 흐름: 왼쪽 위 → 오른쪽 아래 (질문 → 방법 → 결과 → 결론)

**보기 좋게**
- 크기: 학회마다 달라요. 학회 규정을 먼저 확인해요.
- 글씨 (A0 기준): 제목 70 pt 이상, 소제목 40 pt 안팎, 본문 24 pt 이상
- 결론은 따로 상자로 눈에 띄게
- 그림은 Figure 제작소 → HaLab Plots로 다듬어요.

**포스터 앞에서**
- 1분 설명과 3분 설명을 따로 준비해요.
- 상대가 어떤 분야인지 먼저 물어보고 설명 수준을 맞춰요.

---

## 4. 학위 심사

**구성 (30~45분)**
**큰 질문 → 장(chapter)별 질문·결과 → 종합 모델 그림 → 한계·앞으로**

- 논문 여러 편을 하나의 큰 질문으로 묶어요. 장마다 "이 장이 큰 질문의 어느 부분에 답하는지"를 먼저 말해요.
- 종합 모델 그림 한 장으로 전체를 정리해요.
- 한계는 숨기지 말고 먼저 말해요. 다음 연구로 이어지는 질문으로 마무리해요.
- 심사위원 예상 질문은 3장 랩미팅 발표의 "질문받을 때"를 따라 준비해요.

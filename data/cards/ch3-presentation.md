## 1. 우리 연구실 미팅

- 다음 계획 1~2줄

## 2. Progress report — 랩미팅 사이클

**Background → In the previous → Results → Summary → Next plans**

- **Background** — 가장 중요해요. 첫 발표 때 제대로 정리해요: 배경지식, 지금까지 알려진 것과 한계, 연구 목표. 두 번째부터는 1~2장으로 짧게.
- **In the previous** — 지난번 Next plans와 받은 피드백.
- **Results** — 분석마다 *왜 했는지 · 어떤 원리인지* → 결과 → 마지막에 한 줄 요약. 잘 안 된 분석도 보여주고 도움을 받아요.
- **Summary** — 이번에 알게 된 것 3줄 이내.
- **Next plans** — 결과를 근거로 한 다음 단계, 그리고 도움이 필요한 것.

> 받은 피드백을 발표 기록에 남기면, 다음 발표의 **In the previous**가 돼요.
> 그림을 최대한 쓰고 글은 줄여요. 설명은 말로 해요.

## 3. Journal club

**목적:** 논문 결과를 소개하는 게 아니라, 모두가 같이 공부하는 시간이에요.
주로 **새 분석 방법·알고리즘**을 만든 논문, **여러 오믹스를 합친** 논문(어떻게 통합했는지)을 골라요.

1. **배경 · 질문** — 기본 개념은 선행 논문의 실제 figure로 설명. 선행연구가 못 푼 것 → 이 논문의 질문
2. **Study design** — 질문에 답하려고 어떻게 설계했나 (보통 Figure 1A: 샘플, 데이터 종류, 조직·세포)
3. **결과 + 방법** — 결과마다 그 결과를 낸 방법을 같이. 결과 자체보다 **figure끼리 어떻게 이어지는지**, 이야기 흐름에 집중
4. **한계 · 열린 질문** — 무엇이 아직 안 풀렸나
5. **우리 연구와 연결** — 내 연구에 가져올 점 + 토론 질문 2~3개

> 3장 "Methods 해부하기"에서 쓴 노트를 그대로 발표 뼈대로 쓸 수 있어요.

## 4. 슬라이드 만들기

**한 장 = 한 메시지.** 슬라이드 제목에 그 장의 결론을 문장으로 써요.
✗ "Result 2" → ✓ "환자군에서 염증 유전자 발현이 늘었어요"

**데이터 슬라이드 한 장의 틀**
1. 제목: 결론 한 문장
2. 무엇을 했나: 작은 모식도 (샘플 · 처리 · 분석)
3. 결과: 그래프 하나를 크게, 봐야 할 곳에 표시
4. 아래 한 줄: 그래서 무슨 뜻인지 (다음 장으로 이어지는 질문)

**분량:** 1장 ≈ 1분, 데이터 장은 1.5~2분 (15분 발표 ≈ 12~15장)

**보기 좋게**
- 글씨: 제목 28~36 pt, 본문 18 pt 이상, 그래프 축 14 pt 이상
- 본문 3~5줄, 문장보다 짧은 구절
- 글꼴 한 가지, 굵기로만 구분
- 색: 기본 2~3색 + 강조 1색. 빨강·초록 같이 쓰지 않기
- 논문 그림은 통째로 붙이지 말고 필요한 패널만 크게
- 슬라이드 번호 넣기 (질문받을 때 편해요)
- 그림은 Figure 제작소 → HaLab Plots로 다듬어요

## 5. 연습 · 질의응답

**발표 전 체크리스트**
- [ ] 제목만 넘겨 읽어도 이야기가 이어지나요?
- [ ] 모든 그래프에 축 이름 · 단위 · n · 통계 표시
- [ ] 약어는 처음 나올 때 풀었나요?
- [ ] 시간 재며 소리 내어 2번 연습
- [ ] 예상 질문 5개와 답, 보충 슬라이드는 맨 뒤에

**자주 하는 실수**
- 슬라이드에 글을 다 쓰고 읽기 → 할 말은 발표자 노트에
- 결과 장이 너무 많음 → 메시지에 필요한 것만, 나머지는 보충 슬라이드로
- "보시다시피…" → 무엇을 봐야 하는지 직접 말하기
- 잘 안 된 결과 숨기기 → 랩미팅에서는 오히려 꼭 보여주기

**질문받을 때**
1. 끝까지 듣고, 짧게 다시 말해요 ("○○에 대한 질문이시죠?")
2. 답 → 근거(데이터 · 슬라이드 번호) 순서로 짧게
3. 모르면 "확인해 보겠습니다", 좋은 제안이면 "다음 분석에 넣어 보겠습니다"
